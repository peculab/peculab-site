🦃 感恩節活動時間調查

11/26（四）～ 11/29（日）連假，勾選你可以出席的所有時段，我們會挑選最多人能來的時間！

📋 填寫說明

  1. 識別碼：填一個代表你的代號（例如 email 或手機末四碼），之後要修改時方便主辦人辨認。
  2. 姓名：填你的名字或暱稱。
  3. 勾選時段：在下方表格勾選所有你可以出席的時段，可以複選。
  4. 按「送出」，看到 ✅ 送出成功 就完成了。
  5. 想修改？直接重新填一次並告訴主辦人，主辦人會以最新一筆為準。

✍️ 我的出席時間

🔧 給主辦人：設定與查看結果
  1. 在 Apps Script 貼上 code.gs，於「專案設定 → 指令碼屬性」新增 NOTION_TOKEN。
  2. 執行 testConnection，確認五個步驟都是 ✅。
  3. 按「部署 → 新增部署作業 → 網頁應用程式」，執行身分選「我」，存取權選「所有人」，複製網址。
  4. 把網址貼到本檔案 SCRIPT_URL 那一行，再把網頁分享出去。
  5. 查看結果：在 Notion 的 Vote 資料庫，用 Select 欄位分組（Group by），每組的筆數就是該時段可出席人數；也可以新增「圖表」檢視，一眼看出哪個時段最多人。

每勾一個時段，就會在 Notion 新增一列（ID、Name、Select），所以一個人勾 3 個時段會有 3 列。
